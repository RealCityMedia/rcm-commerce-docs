Build a storefront

Connect a custom site to RCM Commerce, fetch a catalog, and hand checkout to the platform.

Get the origin and keys

Ask the store owner for the API origin and full Website key from Settings → Website. The shared origin is https://realcitycommerce.com. Use X-RCM-Key on storefront API requests.

KeyWhere to use it
rcm_pk_…Browser or server for public catalog, checkout, showcases and other storefront calls.
rcm_sk_…Server environment only. Required for the order-list endpoint.
Keep key rotations coordinatedReplacing a key revokes the old value immediately. Update the deployed integration with the new full value.

Load a catalog

JavaScript
const api = "https://realcitycommerce.com";
const headers = { "X-RCM-Key": "rcm_pk_YOUR_WEBSITE_KEY" };
const response = await fetch(api + "/v1/storefront/products?limit=24", { headers });
if (!response.ok) throw new Error("Could not load products");
const { products, total } = await response.json();
const images = products.flatMap((p) => p.images.map((src) => new URL(src, api).href));

The API returns Active products. Use collections for navigation and variant IDs for cart lines. Format amounts from integer cents and the store currency. For bilingual catalogs, pass lang=fr or lang=en on product requests. An untranslated field falls back to the store’s original text.

Send shoppers to hosted checkout

JavaScript
const checkout = await fetch(api + "/v1/storefront/checkout", {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json" },
  body: JSON.stringify({
    items: [{ variantId: selectedVariantId, quantity: 1 }],
    successUrl: location.origin + "/thanks",
    cancelUrl: location.origin + "/cart",
  }),
});
if (!checkout.ok) throw new Error("Checkout could not start");
const { url, orderId } = await checkout.json();
sessionStorage.setItem("rcm-checkout-order", orderId);
location.assign(url);

On return, use GET /v1/storefront/checkout/{orderId}/confirm and read paid and status. A success-page visit alone gives no payment confirmation. For pay-later orders, display the returned instructions when available. On cancellation, keep the cart so the customer can retry.

Embed or design a showcase

HTML
<rcm-collaborations data-key="rcm_pk_YOUR_WEBSITE_KEY"
  layout="grid" heading="Selected work"></rcm-collaborations>
<script src="https://realcitycommerce.com/collaborations.js" defer></script>

Use grid, list or featured. Load the script once per page. Set section="Music" to filter, lang="fr" for French, or heading="" to hide the heading. The element occupies no space when disabled or empty.

CSS
rcm-collaborations {
  --rcm-collaboration-color: #20211e;
  --rcm-collaboration-surface: #fff;
  --rcm-collaboration-border: #d7d7cf;
  --rcm-collaboration-radius: 0;
  --rcm-collaboration-gap: 1.25rem;
}
rcm-collaborations::part(title) { font-weight: 650; }

Other available variables control the font, image background, padding, and accent. For fully custom markup, fetch GET /v1/storefront/collaborations and render id, title, company, image, and section in your own components. Respect enabled and resolve image paths against the API origin.

Content Security PolicyIf your site uses CSP, allow the API origin for the embed script, stylesheet and API connection. Allow the hosts that serve your collaboration images.

Add chat, pop-ups, or order lookup

  • Chat loads with <script src="https://realcitycommerce.com/chat.js" data-key="rcm_pk_…" defer></script>. For a custom conversation interface, use the chat endpoints and keep conversation tokens scoped to the shopper.
  • Pop-ups come from GET /v1/storefront/popups. Display upcoming or current events while the feature is enabled.
  • Order lookup uses the customer’s reference plus the phone number or email on their order. Submit this in a request body to POST /v1/storefront/orders/lookup so the details stay out of the page URL.

Use the SDK when available

If your project has access to @rcm/commerce, it provides a typed wrapper around the same storefront API. The HTTP examples work with any frontend or server runtime that can make HTTPS requests.

TypeScript
import { RcmCommerce } from "@rcm/commerce";

const rcm = new RcmCommerce({
  apiUrl: "https://realcitycommerce.com",
  apiKey: "rcm_pk_YOUR_WEBSITE_KEY",
});
const { products } = await rcm.products.list();
const { enabled, collaborations } = await rcm.collaborations.list();

See the API reference for request fields, responses, and authentication.
