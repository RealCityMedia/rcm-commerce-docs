# RCM Commerce Documentation

Start with the [documentation site](https://realcitymedia.github.io/rcm-commerce-docs/) for searchable guides and examples.

- [Store owner quickstart](Store-owner-quickstart) covers setup, catalog, payments, and a test order.
- [Developer guide](Developer-guide) covers API keys, products, hosted checkout, and collaboration integrations.
- [API reference](https://realcitymedia.github.io/rcm-commerce-docs/api.html) lists the public storefront endpoints and their request fields.
- [Troubleshooting](https://realcitymedia.github.io/rcm-commerce-docs/troubleshooting.html) covers sign-in, checkout, missing products, and embeds.
