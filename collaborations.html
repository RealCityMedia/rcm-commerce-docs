Showcase collaborations

Build a portfolio of past work, preview it, and connect it to your website whenever you are ready.

Create an entryChoose how it looksHide or publish the showcase

Create an entry

  1. Open Products → Collaborations → Add collaboration.
  2. Enter a product or project name, the company it was made for, and an image. Upload a photo or paste its full image URL.
  3. To group related entries, give them the same Subsection name. Leave it blank for entries that only need the main showcase.
  4. Use Storefront preview to check the image and text before saving. The entry is a portfolio piece with no checkout controls.
Choose an image you have permission to showUse a clear photograph or product mockup with room around the subject. Check the preview for long names or narrow photos.

Choose how it looks

LayoutWhat visitors see

Custom frontendYour developer uses the API to build the layout and interactions.

Open Settings → Website → Collaboration layouts, select a preset and copy the embed. Replace the example value with your full Website key and add the code to an HTML block where the showcase belongs.

For colours, fonts, subsection filters and a custom design, see the collaboration integration guide.

Hide or publish the showcase

  1. Leave the switch off in Settings → General → Collaborations while you prepare your entries.
  2. When the website is connected and you are ready, enable Show Collaboration on your website and save.
  3. Visit the website in a private window. Check that your entries and images appear as intended.

Turning the switch off keeps your entries in the dashboard and hides the preset. A custom frontend should check the API’s enabled flag before showing its showcase.
